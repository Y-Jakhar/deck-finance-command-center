# Contributing

Deck source owned by Yash Jakhar is licensed under MIT. Third-party material keeps its original terms; see [third-party notices](THIRD_PARTY_NOTICES.md). External contributions should identify their author and license compatibility and must not introduce copied code or assets without documented redistribution rights.

Use synthetic, mathematically checked fixtures for calculation changes. Preserve validated financial engines and frozen research unless a change is explicitly scoped and reviewed. Run backend tests, frontend tests, the production build, lint, and dependency audits before proposing changes.

Do not include credentials, real portfolio records, archived research, downloaded market data, filings, local paths, databases, private screenshots, or generated build outputs. Report security concerns privately to the maintainer without including secret values.
